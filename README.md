## Report Builder V23 — 9 October 2026

Download [Report-Builder_V_23.html](https://raw.githubusercontent.com/mixkung2540-ctrl/Combine-Report/main/Report-Builder_V_23.html) and open it in your browser.

Existing V22 users: click the program's update button to check for V23 and download it. Save the new file using your previous filename and location in the same browser if you want to retain your existing draft. Export important drafts before replacing files.

### Changes

- AC Endorsement / PE Endorsement selection, saved with drafts.
- Long cover titles wrap within the frame.
- Single-file categories omit redundant subheadings and file divider pages.
- Centred page numbers in the table of contents.
- Arial for generated report pages (imported PDF pages remain unchanged).
- EA company logo and company wording at the upper-left of the contents page.

The update notice is available through the existing update button. V22 does not check automatically or send desktop/email notifications.
